# Private AMM v10 circuit (M5 Fast mode, pipelined verification)

`fast_verify_chain_v1`: the batch verification of `v9/fast_verify_v1`, but starting from the previous batch's claimed pool. It lets the program verify batch k+1 while batch k is still being verified (SPEC §16.8). Source: branch `m4/trading-accounts` of the private launchpad prototype, `amm-v5/encrypted-ixs` (generated by `scripts/gen-fast.mjs`). Arcium 0.15.0. Prototype only: unaudited, devnet test use.
