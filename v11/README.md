# Private AMM v11 circuit (M5 Fast mode, pipelined verification)

`fast_verify_chain_v1` (supersedes the v10 draft, which no deployed program pins): the batch verification of `v9/fast_verify_v1` for up to 9 orders, starting from the previous batch's claim. The pool comes from that claim, and an account that is also in the previous batch starts from its claimed state there (a public one-hot slot mask per order). It lets the program verify batch k+1 while batch k is still being verified (SPEC §16.8). Source: branch `m4/trading-accounts` of the private launchpad prototype, `amm-v5/encrypted-ixs` (generated by `scripts/gen-fast.mjs`). Arcium 0.15.0. Prototype only: unaudited, devnet test use.
